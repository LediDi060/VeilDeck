# Подготовка синтетических материалов (4.3 / 4.6)

Внутренний `app.cards.service.prepare_material` проверяет роль admin, валидирует PDF/PNG/JPEG
и записывает файл под UUIDv4 в заранее созданный закрытый каталог. Имя клиента не используется
как путь; файл создаётся эксклюзивно с правами 0600. При ошибке записи неполный файл удаляется.
Результат содержит `storage_key`, MIME, размер, SHA-256 и число страниц (для изображения — 1).

```python
from pathlib import Path
from app.cards.service import prepare_material

prepared = prepare_material(
    principal,  # только из доверенной серверной сессии
    data=synthetic_bytes,
    filename="synthetic.pdf",
    declared_mime="application/pdf",
    storage_directory=Path("/data/materials"),  # из конфигурации, вне веб-корня
)
```

Принимается непустой файл ≤10 МиБ, PDF — 1–30 страниц. Расширение, заявленный MIME и сигнатура
должны совпадать. Имена с путями, управляющими символами или несколькими расширениями отклоняются.
Pillow проверяет целостность и декодирование изображений; предупреждение о decompression bomb — отказ.
MuPDF разбирает PDF и нормализует имена объектов, включая экранирование `#XX`. Шифрование
(даже с пустым паролем), JavaScript, встроенные файлы и восстановленная повреждённая структура отклоняются.
Проверка опасных имён консервативная: маркер внутри строкового значения объекта тоже может вызвать отказ.
`MaterialRejected.reason` содержит только безопасный код причины, без данных файла.

Это этап подготовки, а не готовый HTTP upload. Перед подключением маршрута обязательны:
проверка существования карточки, лимит 10 материалов на карточку с защитой от гонки,
транзакционная запись `materials`, аудит `material.upload_rejected` / `authz.denied`, CSRF и rate limit.
После сбоя транзакции вызывающий код обязан удалить подготовленный файл. Каталог не должен
раздаваться nginx. Состояние задачи 4.3 не считается завершённым.

Связь с моделью угроз: роль — T-07/SR-16; хранилище — T-11/SR-24;
ресурсные ограничения — T-16/SR-25. Аудит SR-26 остаётся обязательным для HTTP-интеграции.

Проверки из `backend/`: `pytest -q tests/test_materials.py`, `ruff check .`, `lint-imports`.
